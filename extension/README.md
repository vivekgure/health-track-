# LifeSync Chrome Extension Companion

This is the official browser companion extension for LifeSync. It provides true distraction-free focus sessions and browser screen-time accountability.

## Why this exists
Standard web applications operate inside the browser sandbox and cannot directly intercept tab navigations or inspect activity across other tabs or desktop applications. This companion extension connects with LifeSync to:
1. **Enforce Focus Mode Website Blocking**: When you turn on Focus Mode in LifeSync, this extension redirects distracting domains (e.g. YouTube, Reddit, Twitter, Facebook, TikTok) to the peaceful LifeSync Mindful Breathing screen.
2. **Track Domain Screen Time**: Accurately measures time spent on active browser tabs and sends summary logs to your LifeSync database.
3. **Notify on Screen Time Limits**: Fires browser notifications when daily screen time limits are approaching.

## Installation in Google Chrome / Edge / Brave / Opera
1. Open Chrome and go to `chrome://extensions/`.
2. Toggle **Developer mode** in the top right corner.
3. Click **Load unpacked**.
4. Select this `extension` folder located inside your LifeSync project directory.
5. The LifeSync icon will appear in your Chrome toolbar!
